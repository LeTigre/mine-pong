# Mine Pong — веб-версия

Есть два варианта одной и той же игры:

1. **`MinePong v2.9.html` в корне проекта** — один файл, всё внутри (иконки и
   манифест вшиты как data URI). Скидываете друзьям, они открывают — работает.
   Собирается из этой папки командой `.\build.ps1`.
2. **Эта папка** — то же самое, но для публикации по ссылке. Тогда игра ставится
   на экран «Домой» с иконкой, открывается на весь экран и кэшируется офлайн.
   Единственный вариант, который нормально работает на iPhone.

Дальше — про второй.

Одна ссылка, которая работает везде: iPhone, iPad, Android, Windows, Mac, Linux.
На телефоне ставится на экран «Домой» и запускается как обычное приложение —
на весь экран, без адресной строки, без интернета.

## Что в папке

| Файл | Зачем |
| --- | --- |
| `index.html` | сама игра (тот же движок, что в APK, плюс правки под браузер и iOS) |
| `manifest.webmanifest` | имя, иконка и режим «на весь экран» при установке |
| `sw.js` | service worker: кэширует игру, чтобы работала офлайн |
| `icon-*.png`, `apple-touch-icon.png` | иконки для рабочего стола |

## Как опубликовать (GitHub Pages, бесплатно, ~5 минут)

1. Заведите репозиторий на github.com, например `mine-pong`.
2. Загрузите туда **содержимое** этой папки (файлы должны лежать в корне репозитория,
   а не внутри вложенной папки `web`).
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две адрес будет такой: `https://letigre.github.io/mine-pong/`

Https обязателен — без него не работает офлайн-кэш. GitHub Pages даёт его сам.

## Как поставить на телефон

**iPhone / iPad:** открыть ссылку **в Safari** (в Chrome на iOS кнопки установки нет) →
«Поделиться» → «На экран Домой» → «Добавить».

**Android:** открыть в Chrome → меню (⋮) → «Установить приложение».

**Windows / Mac:** открыть в Chrome или Edge → иконка установки в адресной строке.
В Safari на маке — «Файл» → «Добавить в Dock».

Дальше игра запускается с иконки и работает без интернета. Интернет нужен только
для режима игры по сети.

## Как переслать одним файлом

```powershell
.\build.ps1
```

Соберёт `MinePong v2.9.html` в корне проекта — один файл, 254 КБ, ничего рядом
не нужно. Запускайте после каждой правки `docs\index.html`, иначе пересылаемая
версия отстанет от опубликованной.

Кому как открывать:

| Куда | Как | Итог |
| --- | --- | --- |
| Windows, Mac, Linux | двойной клик по файлу | работает полностью |
| Android | сохранить и открыть в Chrome | работает полностью |
| iPhone | сохранить в «Файлы» и нажать | игра запустится в предпросмотре, но без иконки на рабочем столе и не на весь экран |

На айфоне пересылка файлом — самое слабое место: iOS не умеет открывать
локальные HTML в Safari как страницу, только в предпросмотре «Файлов». Друзьям
с айфонами лучше давать ссылку.

## Как обновить игру

Залили новый `index.html` — **обязательно поднимите версию** в `sw.js`:

```js
const CACHE = "minepong-v2.9.1";   // было v2.9.0
```

Иначе телефоны, где игра уже установлена, продолжат запускать старую версию из кэша.

## Локальная проверка

Из папки проекта:

```bash
python -m http.server 8123 --directory docs
```

Затем открыть `http://localhost:8123`. Localhost считается доверенным адресом,
поэтому офлайн-кэш там тоже работает и его можно проверить, остановив сервер
и перезагрузив страницу.

Чтобы открыть с телефона в той же Wi-Fi сети — узнайте IP компьютера
(`ipconfig`) и зайдите на `http://192.168.X.X:8123`. Игра запустится, но
установка на экран «Домой» и офлайн-режим по такому адресу работать не будут:
для них нужен https, то есть публикация.

## Чем эта версия отличается от исходного `mine-pong-mobile.html`

- настройки, ник, тема и рекорды сохраняются в `localStorage`
  (в исходнике эти хуки были заглушками, их подставляла Android-обёртка);
- отключены зум по двойному тапу и «резинка» при протягивании страницы на iOS —
  раньше поле могло уехать посреди розыгрыша;
- звук доп. разблокируется по касанию и восстанавливается при возврате в игру:
  Safari глушит аудио-контекст, когда приложение уходит с экрана;
- пересчёт размера поля при изменении visual viewport — это когда в Safari
  выезжают и прячутся панели;
- HUD и панель кнопок ограничены 900 px на больших экранах, чтобы на мониторе
  всё не растягивалось на всю ширину;
- добавлены манифест, иконки и офлайн-кэш.

Известное ограничение iOS: жёстко зафиксировать ориентацию из браузера нельзя
(`screen.orientation.lock` в Safari не поддерживается), поэтому переключатель
поворота на айфоне влияет только на то, как игра рисует поле. На Android и на
десктопе он работает полностью.

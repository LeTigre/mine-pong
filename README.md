# Mine Pong

Пиксельный пинг-понг: один игрок против ИИ, двое на одном экране или игра по сети.
Восемь тем оформления, синтезированная музыка и звук без единого аудиофайла,
русский / украинский / английский.

**Играть:** https://letigre.github.io/mine-pong/

Открывается в любом браузере. На телефоне ставится на экран «Домой» и работает
офлайн: Safari — «Поделиться» → «На экран Домой», Chrome — меню → «Установить
приложение».

## Что где лежит

| Путь | Что это |
| --- | --- |
| `docs/` | опубликованная версия, отсюда GitHub Pages берёт сайт |
| `docs/index.html` | исходник игры — правки вносить сюда |
| `MinePong v2.9.html` | та же игра одним файлом, чтобы просто переслать |
| `build.ps1` | пересобирает файл выше из `docs/` |
| `MinePong v2.9.apk` | сборка под Android (собрана из устаревшего кода, см. ниже) |
| `mine-pong-mobile.html` | как выглядел файл до правок; **для сборок не использовать** |

Подробности про публикацию и установку — в [docs/README.md](docs/README.md).

## Android

`docs/index.html` кладётся в APK как `assets/index.html` без единой правки —
отдельной версии под Android больше нет. Внутри APK этот же файл:

- сохраняет настройки в `localStorage`, который WebView хранит между запусками;
- читает и старые ключи `minePongSettingsV1` / `minePongBestStatsV1`, поэтому у
  тех, кто уже играл в APK 2.9, настройки и рекорды не обнулятся;
- сам находит мост `AndroidApp.setRotationEnabled`, если приложение его даёт;
- не регистрирует service worker: адрес `file://` под это условие не подходит.

Ссылки на манифест и иконки внутри APK ведут в никуда и дают две записи 404 в
логе WebView — на игру это не влияет.

`MinePong v2.9.apk` в репозитории собран **до** исправления привязки к частоте
экрана, то есть на телефоне со 120 Гц идёт вдвое быстрее нужного. Чтобы
пересобрать, нужен Android-проект (в этом репозитории его нет), JDK, Android SDK
и тот самый ключ подписи `MINEPONG` — без него APK не встанет поверх
установленного, только через удаление старого.

## Разработка

```bash
python -m http.server 8123 --directory docs
```

Дальше `http://localhost:8123`. После правок `docs/index.html` пересоберите
файл для пересылки:

```powershell
.\build.ps1
```

И поднимите версию кэша в `docs/sw.js`, иначе у тех, кто уже установил игру,
останется старая версия.
